# DonutFlip Predictor

The official Windows predictor for [DonutFlip](https://YOUR-SITE-LINK-HERE). It gives you predictions for coin flips, roulette, blackjack and more.

**DonutFlip uses play money only. There is no real-money gambling.**

## Download

Get `DFPredictor.exe` from the [Releases page](../../releases/latest).

## How to use

1. Download `DFPredictor.exe` from the latest release.
2. Double-click the file to run it. There is no installer.
3. Pick your game and use the predictor while you play on DonutFlip.

## Requirements

- Windows 10 or 11 (64-bit)
- An internet connection

## Windows warning

When you first open the file, Windows SmartScreen may show "Windows protected your PC". This happens because the app is not code-signed yet, and new apps from small developers often get this message.

To run it anyway, click **More info**, then **Run anyway**.

## Verify your download

You can check that your file is the official one. Open PowerShell in the folder where you saved it and run:

```
Get-FileHash .\DFPredictor.exe -Algorithm SHA256
```

The result should match this hash exactly:

```
cf0af19de4a003edbca808b4770c538d36f76aec984affea9a0f4e6483296f2d
```

If it doesn't match, delete the file and download it again from this page. Only download from this repository or from the official DonutFlip site.
