# DonutFlip Predictor

The official Windows predictor for [DonutFlip](https://donutflip.net/). It gives you predictions for coin flips, roulette, blackjack and more.

**DonutFlip uses play money only. There is no real-money gambling.**

## Download

Get `DFPredictor.exe` from the [Releases page](../../releases/latest).

## How to use

1. Download `DFPredictor.exe` from the latest release.
2. Instantly launch the predictor from your downloads folder.
3. Pick your game and use the predictor while you play on DonutFlip.

## Requirements

- Windows 10 or 11 (64-bit)
- An internet connection

## Windows warning

When you first open the file, Windows SmartScreen may show "Windows protected your PC". This happens because the app is not code-signed yet, and new apps from small developers often get this message.

To run it anyway, click **More info**, then **Run anyway**.
